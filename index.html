02 / COUNTER LOGIC

One edge. One increment.

All four bits update together on the rising edge of clk. When rst is high, that edge clears the count instead.

Decimal 0Ready for a rising edge.

Toggle reset, then apply a clock edge. Reset is synchronous: it does not clear the count immediately.

counter.v Download ↓
always @(posedge clk) begin
    if (rst)
        count <= 4'b0000;
    else
        count <= count + 1;
end
WHY DOES IT WRAP?

Four bits can hold only 0–15. Adding one to 1111 drops the carry and leaves 0000.

Read the signals in plain English +

clk — the input clock; only its rising edge triggers an update.

rst — the reset input; high means clear to zero at the next rising edge.

count[3:0] — the four output bits, interpreted as a number from 0 to 15.

Before running the flow again +
  1. Install the licensed Cadence tools and the GPDK090 libraries. The library files are not included.
  2. Update the library paths in syn.tcl and invs.tcl for your environment.
  3. Run scripts from their respective synthesis and physical-design directories so relative paths resolve.
  4. Configure timing libraries and constraints in Innovus before attempting timing analysis.
  5. Review the simulation logs: the original Xcelium run failed; the supplied waveform comes from a separate Yosys model.
