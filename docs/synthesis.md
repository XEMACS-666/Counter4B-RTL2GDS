# Synthesis

The historical reports were generated by Cadence Genus 21.14-s082_1 on September 17, 2026. The original script referenced a 90 nm `typical.lib` installation. That library is not part of this repository.

## Running the prepared flow

From the repository root, set `COUNTER_LIB` to an accessible compatible Liberty file and run `make synthesis`. The script derives paths from its own location, reads `src/counter.v`, elaborates `counter`, applies the saved SDC, and runs generic synthesis, mapping, and optimization. Reports, the netlist, and exported SDC go to `build/synthesis/`.

The original script created the 10 ns clock directly. The prepared script reads the exported SDC, including its units, wire-load mode, and clock-gating check. This adaptation has not been rerun with Genus; it is not a claim of exact historical reproduction. A different library or tool version can change the mapping and results. The supplied Python checker supports the cell types in the saved netlist only.

## Reading the results

- **Timing:** The SDC defines a 10 ns clock. The saved report shows +9586 ps setup slack on the displayed register-to-register path. It does not establish post-route timing closure or maximum operating frequency.
- **Area:** The report records 14 cells with cell area 99.911. The library's physical area unit is unavailable, so square micrometres are not asserted.
- **Power:** The subtotal is 8.83596e-6 W. It is an estimate; stimulus/activity assumptions have not been established.

The scope ends at synthesis. Exploratory PNR/GDS artifacts and historical DRC evidence are included under `history/`. They do not establish physical sign-off, post-route timing closure, or silicon measurement. See [failures and progress](failures-and-progress.md).
